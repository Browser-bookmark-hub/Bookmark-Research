# 比较、核验与排行榜分析

[English](../research-methods.md) · **中文阅读版**

按研究问题选用方法，不要求每次简单查找都跑完整分析。读者和独立核验者共享问题、冻结的 inventory ID、交付维度与证据格式，具体并发交给宿主。原包的分类和连线帮助理解意图，不自动证明网页事实。

## comparative_analysis：同维度比较

先确定比较对象的层级：搜索／提取工具、持续研究服务、代理框架、宿主、工作流扩展与知识存储是不同对象。一个 SDK 不因存在子代理就等同于 Deep Research API；一个搜索 MCP 不因有多种工具就等同于研究流程。

针对用户决策选维度，例如能力与输入、认证、资料访问方式、执行归属、结果与引用、取消／恢复、成本／配额、接入条件。每格保存结论、出处与适用版本；没有证据填未知，不用空白或名称推断支持。

| 对象 | 维度 | 结论 | 依据性质 | 日期／版本 | 证据 ID、原句与限制 |
| --- | --- | --- | --- | --- | --- |
| 本次实际对象 | 本次实际维度 | 有边界的判断 | 文档声明／当前可见／已实测 | 实际值或未知 | 原始来源与结论的对应关系 |

文档声明用于描述产品契约；当前工具／配置证明发现了入口；完整运行才能证明当前环境的结果。分别填写，不能用通过 schema 验证推断模型工作流可运行。判断“支持恢复”时写明同会话、跨会话、重放范围和幂等限制。认证字段区分搜索、研究任务与用户网页登录。

先用用户的全部原始资料建立这张矩阵，再按证据缺口补查一手文档。不能因外部搜索更方便就替换掉原调研包。不同时间、套餐或版本的差异先核对条件，再记录冲突。

交付同维度矩阵、对当前任务的选择依据与局限。建议写成“在条件 A 下选择 B，因为证据 C；条件 D 还未验证”，不要按工具数量直接给总体优劣排名。

## fact_check：原子命题与反证

把复杂陈述拆成可分别支持的原子结论。例如“某宿主有子代理、后台工作流且可跨会话恢复”至少有三项不同契约。为每项检查：

- 页面是否属于正确实体、版本与时期；提取结果是否是错页、登录壳、摘要或截断内容。
- 原句是否支持整个命题，包括条件、数量、默认开启与否；引文存在只能通过文本检查。
- 是否有直接一手证据与独立反证；多家搜索服务返回同一篇网页不增加独立来源数量。

保存 `source_review` 后写 `claim` 与原样 `quote`。推断用 `inference:true`，说明从哪些事实推得，不能把推断写成文档声明。发现证据失效用 `retraction`，修订对应问题；版本矛盾用 `conflict`／`resolution` 保留两边材料和解决依据。

独立核验者阅读原文和结论后返回：支持／不支持／仍不确定、理由、反证、需补查的 inventory ID 或 question ID。核验不能只复述读者的总结。检查完成后再看 `research_coverage`；记录齐全和语义可靠是两个检查层。

## benchmark_review：排行榜的可比范围

原包包含多个排行榜、基准或论文时，逐项记录测量对象与协议；不要只读取当前榜首。把排行榜、基准任务、参评系统和本插件分开描述。

| 应记录内容 | 对比较的影响 |
| --- | --- |
| 任务、样本数、语言、时间切分与开放／私有数据 | 决定能推广到哪些问题 |
| 模型、版本、推理配置、宿主与 agent 框架 | 分数可能来自模型和执行策略，不是搜索服务本身 |
| 搜索／浏览／文件工具、是否使用外部研究 API | 工具可达性不同会改变资料范围 |
| token、调用、时间与费用预算，重试／best-of-N 政策 | 更多预算与择优结果不能直接对照单次运行 |
| 金标准、答案匹配、语义引用裁判、评分 rubric | F1、引用存在率、引用准确率与报告评分不是同一指标 |
| 失败、拒答、缺失来源是否进入分母 | 只算成功任务会夸大结果 |
| 重复次数、波动、置信区间、排行榜更新日 | 单次排名不能证明稳定优势 |

缺失信息保留未知。先分同任务、同输入、同条件的结果，再说明不可比差异；不能将框架榜单当搜索 API 排名，也不能将本地合成测试写成公众榜单分数。涉及 RACE／FACT 等命名评分时，只有真正采用其实现和协议才能使用该名称。

比较本插件三条执行路线时，准备同一冻结资料、问题、交付要求和预算，保存实际模型、工具与宿主版本。保留失败输出与未知费用，独立标注答案匹配、引用语义和报告质量，再交给 [评测工具](wiki-and-evaluation.md) 计算。专业服务的不可见模型／工具差异必须披露；不能凭 API 调用成功宣布质量提升。
